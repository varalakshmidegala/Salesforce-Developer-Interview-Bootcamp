# Sprint 03 – Validation Rules, Flows & Declarative Automation

## Objective

The objective of Sprint 03 was to enhance the Placement Management System using Salesforce declarative automation by implementing Validation Rules and Record-Triggered Flows.

## Business Scenario

The Placement Cell required additional automation to improve the application process. The system should automatically populate fields, enforce business rules, and automate repetitive tasks while minimizing Apex code.

## Features Implemented

* Created a Record-Triggered Flow to automatically populate the Application Date.
* Implemented Validation Rules to enforce data quality.
* Explored automation for Offer Letter creation.
* Compared Validation Rules, Flows, and Apex Triggers to determine the best solution for different business requirements.

## Technologies Used

* Salesforce Flow Builder
* Validation Rules
* Salesforce Developer Edition
* Apex (existing project)
* VS Code
* Git & GitHub
