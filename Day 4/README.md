# Day 4 – Your First Lightning Web Component

## Project

Placement Management System

## Objective

The objective of Day 4 was to create the first user interface of the Placement Management System using Lightning Web Components (LWC).

## Component Created

Component Name:

placementHome

## Technologies Used

- Salesforce
- Lightning Web Components
- HTML
- JavaScript
- Salesforce Lightning App Builder
- VS Code
- Salesforce CLI

## Features Implemented

### 1. Placement Portal

Created a Lightning Web Component named placementHome and deployed it to Salesforce.

### 2. Student Details

Displayed:

- Student Name
- Roll Number
- Department

### 3. Data Binding

Used JavaScript properties in the HTML template to display student information.

### 4. Welcome Message

Created a button that displays:

"Welcome to Salesforce Development."

### 5. Application Status

Implemented a button that changes:

Not Applied → Applied

### 6. Placement Dashboard

Displayed:

- Number of Companies: 25
- Number of Jobs: 63
- Applications Submitted: 5

These values were hard-coded as required by the assignment.

## LWC Files

### placementHome.html

Contains the user interface and Lightning components.

### placementHome.js

Contains JavaScript properties, event handlers and component logic.

### placementHome.js-meta.xml

Defines component metadata and exposes the component to Lightning pages.

## What I Learned

- What Lightning Web Components are.
- Structure of an LWC.
- Data binding.
- JavaScript event handling.
- How to deploy an LWC to Salesforce.
- How to add an LWC to Lightning App Builder.
- How LWC can later communicate with Apex.
